# Semantic F1 Validation Experiments

## Installation

`pip install -e .[dev]`

## OpenAI

To run OpenAI experiments, please create and `.env` and include `OPENAI_API_KEY=<your_key>`.

## Scripts

All scripts to run all of the analyses can be found under `./scripts/semantic_f1`. There, you will also find the mapping between the name of the study in the paper to the name of the script. Enjoy!
